# v0.1.1 — LinkedIn positioning and optional field execution

Ask your preferred AI to help update your LinkedIn profile using the evidence, goals and voice already developed in the pipeline. The human/agent guides now lead into paced profile review, positioning choices, public-disclosure checks, copy-ready sections and an honest per-field publication ledger. Pasted text is enough to begin; no code, install, LinkedIn connection or completed résumé is required for the prompt workflow.

An optional standard-library Python bridge lets a capable, permitted host agent coordinate individually approved headline, About and stable experience-entry body updates. It supplies exact-field approvals, capability/source checks, a durable one-time dispatch journal and conservative readback/uncertainty states. Skills, titles, dates, media and settings remain manual-only. No live LinkedIn API integration or browser driver is bundled or tested; the reference host operates only a fictional local JSON file.

Verification: 80 local regression tests pass, including 35 new profile tests; the source/link/privacy preflight and fictional walkthroughs pass. Independent review found no remaining substantive issues after fixes. No GitHub Actions workflow is configured in this release; local test results are not a CI pass. Actual consent, public disclosure, account identity, permitted tools and genuine live observations remain host/person responsibilities.

The kit sends no LinkedIn post and performs no real profile edits itself. Feedback is welcome using fictional examples only; never put résumés, private profile snapshots, approvals or credentials in public issues. Existing Apache 2.0 / CC BY 4.0 file scopes and James E. Dunn attribution are unchanged.

# v0.1.0 — early release, open to feedback

A provider-neutral starter kit for people and their preferred AI assistants. Start with paced career consultation, preserve a broad evidence bank, build truthful résumé material, and maintain an agent-owned role roster with clear decisions.

Included: human/agent start guides, role runbooks, reusable prompts/templates, session capability orientation, bounded private improvement records, fictional examples and an optional standard-library Python CLI for local state checks, next actions, reminder planning and editable packets.

The CLI does not call models, browse jobs, send reminders, upload materials or submit applications. Those capabilities require a person, capable agent or separately reviewed adapter. A ready packet is not a submitted application; official posting checks and exact-material approvals remain explicit.

This is an early release. Feedback on clarity, friction, missing edge cases and provider portability is welcome. Actual novice usability and every named provider have not been tested. Use fictional reproductions in public issues: do not post résumés, contact information, private conversations, candidate workspaces, tokens or identifying evidence.
