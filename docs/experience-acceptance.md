# Experience acceptance review

This checks whether the kit reduces a candidate's administrative burden. It complements automated CLI tests; it does not validate a model provider or prove that a first-time user finds the experience usable.

## Acceptance criteria

| Situation | Pass condition |
| --- | --- |
| Novice reads only the human-start guide | Can begin with a preferred agent and whatever material exists, without code, schemas or a mandatory questionnaire |
| Candidate has messy or partial material | Agent inventories and reads it, extracts known answers and asks only material missing questions |
| Candidate has an immediate pressure | Agent prioritizes useful help and paces broader discovery rather than completing intake first |
| Upfront discovery is substantial | Questions are focused, explained and paced; unknown/skip/later remain valid |
| Materials conflict | Agent flags the conflict neutrally with source/date and avoids invented resolution |
| Candidate's work was through a team | Leadership and contribution scope survive editing without claiming all hands-on delivery |
| Candidate returns | Agent recovers the roster, evidence, questions and next actions, then offers a few decisions |
| Capabilities are absent | Agent reports the limit and supplies a useful manual next step without fabricated success |

## Fictional messy-input fixture

Everything below is invented for this review. It describes no real candidate, employer, opening or application deadline.

**Opening message:** “I want internal operations work with less client firefighting. There is one application I care about in two days. I have twenty minutes and an old résumé plus some notes. A draft would help most.”

**Source A — old résumé, saved February 2022:** “Harbor Finch Studio. Project Coordinator, 2019–present. Led onboarding improvements. Familiar with HR systems.”

**Source B — rough notes, saved November 2024:** “Operations lead from Aug 2023? Check date. I designed the onboarding checklist. Team did the rollout. Fewer missed steps but I don't have a count. Started an HR systems certificate module; didn't finish. Volunteer event coordinator before this job.”

**Source C — candidate preference note:** “Remote preferred. Could do two office days for the right role. Please keep questions short today. No posting file yet.”

## Scripted walkthrough actually performed

Review method: an author read the human-start guide as the sole human-facing entry point, then applied the agent-start procedure to the fixture above. The extraction and responses below were produced in this review. This is a scripted review using fictional input, not an empirical novice test or a live provider run.

**Human entry-point finding:** The guide says nothing is mandatory, messy material is acceptable, code is optional, material should be permitted/minimized, and pace can be chosen. Its copyable orientation block is enough to begin with a preferred agent. No setup task is required before the conversation.

**Agent's extracted working state:**

- Immediate goal: a focused résumé draft, within a short session, before the candidate's reported deadline.
- Direction: internal operations; less client firefighting. Remote is a preference, and two office days may be acceptable.
- Prior experience: coordinator role since 2019 according to the old source; possible later promotion according to newer notes. Current title/date needs confirmation.
- Evidence: designed an onboarding checklist and led or contributed to a team rollout. No confirmed numeric outcome.
- Credentials: incomplete learning only; no earned certificate established.
- Broader bank: earlier volunteer coordination should be explored later, not discarded.
- Missing resource: actual posting. No real role can be assessed or verified yet.

**First agent response from the review:** “Let's use the twenty minutes for the draft. I've read the résumé and notes, so you do not need to re-enter them. The older résumé lists coordinator; the newer note suggests a promotion. Two details matter now: should the current title be operations lead from August 2023, and can you share the posting when convenient? I'll draft the confirmed checklist/team contribution without a metric or certificate claim. We can explore the volunteer work later.”

**Scripted candidate reply:** “Yes, operations lead from August 2023. I will send the posting later. Skip numbers and certificates.”

**Agent's next action from the review:** Record the title/date as candidate-confirmed, retain the dated source conflict and its resolution, create a draft from confirmed claims, preserve the team attribution, leave numeric results and credentials out, and mark role-specific tailoring/verification as waiting on the posting. Save the open question and next action itself. Do not ask the person to create a tracker or claim an application is ready.

**Returning check-in from the review:** “The draft uses the title you confirmed and contains no numbers or certificate claim. Two next steps are useful: approve the wording of the onboarding contribution, or share the posting so we can tailor and check it. We can do either in ten minutes; the broader career notes can wait.”

## Results and limitations

The scripted review passes the criteria above: it uses existing answers, reduces the immediate task, preserves uncertainty and team scope, and leaves the person with a small decision set. The partial source set permits an initial draft, not a role-specific final packet or verified opening. No file upload, live browsing, reminder scheduling or application was performed.

An actual novice usability test remains undone. Before a broader release, ask a willing first-time reader to use only [the human-start guide](../START_HERE_HUMAN.md) with a preferred agent and permitted fictional or redacted material. Observe whether they can start without coaching, whether the agent asks them to repeat known facts or administer the tracker, and whether they understand the next decision. Record consent, agent/version, friction and resulting changes without collecting unnecessary private career data. Do not report that future test as completed until it happens.
